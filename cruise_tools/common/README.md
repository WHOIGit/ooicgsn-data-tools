# cruise-tools-common

Shared utilities for cruise_tools sub-packages — part of the
[cruise_tools](https://github.com/WHOIGit/cruise_tools) monorepo.

## Install (from repo root)

```bash
pip install -e common/
```

## Usage

```python
from cruise_tools.common import ...
```

---

> **Note:** This package is a scaffold for utilities shared across tools
> (e.g. date normalisation, cruise metadata helpers, file-discovery).
> Add modules to `cruise_tools/common/` as the need arises.
